# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| 1.x | Yes |

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues, discussions or pull requests.

Report them privately through [GitHub security advisories](https://github.com/ctsoftwarellc/laravel-job-throttle/security/advisories/new). Include the affected version, the steps to reproduce and the impact you expect.

The maintainers will confirm the report, keep you informed while we work on a fix, and credit you in the release notes unless you ask us not to.
